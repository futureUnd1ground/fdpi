FDPI — ручная установка на CachyOS / Arch Linux по шагам

TUI установщика: fdpi (при первом запуске) или fdpi setup. В интерфейсе: i.
Текстовый мастер: fdpi setup --text. Основной интерфейс отдельно: fdpi tui.

Сейчас fdpi может открывать интерфейс без установленного сетевого движка.
Для обработки трафика нужны nfqws2, системные настройки и служба systemd.
Эта справка ничего не устанавливает и не меняет сеть автоматически.

1. Откройте каталог проекта и установите зависимости

{{OPEN_PROJECT}}
sudo pacman -S --needed base-devel go git pkgconf nftables libnetfilter_queue libnfnetlink libmnl sudo

Пароль sudo вводится только в вашем терминале. В чат его отправлять не нужно.

2. Проверьте и соберите программу и движок

make check
make build
make engine

Дождитесь успешного завершения каждой команды. make engine скачивает исходники
закреплённой версии zapret2/nfqws2 и собирает их локально. При ошибке остановитесь
на этом шаге: запуск интерфейса ещё не означает готовность сетевого движка.

3. Установите файлы в систему

sudo make install

Это добавит /usr/bin/fdpi, /usr/lib/fdpi/nfqws2 и fdpi.service.
Работающая конфигурация сохранится, служба автоматически не запустится.
Обычный интерфейс запускайте командой fdpi, без sudo.

4. Включите счётчики соединений для ограничения обработки первыми пакетами

sysctl net.netfilter.nf_conntrack_acct

Если уже указано = 1, для текущего запуска ничего менять не нужно.
Если указано = 0:

sudo sysctl -w net.netfilter.nf_conntrack_acct=1

Чтобы значение сохранялось после перезагрузки, добавьте эту строку в собственный
файл /etc/sysctl.d/70-fdpi.conf:

net.netfilter.nf_conntrack_acct=1

Если такого файла ещё нет, его можно создать командой:

printf '%s\n' 'net.netfilter.nf_conntrack_acct=1' | sudo tee /etc/sysctl.d/70-fdpi.conf

Перед выполнением проверьте, что не перезаписываете существующие настройки.
FDPI не включает этот системный параметр самостоятельно.

5. Для начала включите один сервис, например YouTube

fdpi config enable youtube on
fdpi config strategy youtube light
fdpi apply
fdpi start
fdpi status
sudo /usr/bin/fdpi doctor
fdpi test youtube.com

Настройки пользователя создадутся при необходимости. light — ID лёгкой стратегии.
В интерфейсе она называется «Лёгкая». apply проверит параметры и перенесёт их
в системную конфигурацию. Закрытие интерфейса не остановит службу.
Проверка сайта не доказывает работоспособность видео или обход DPI провайдера.

6. Откройте интерфейс и настройте остальные сервисы

fdpi

Tab — разделы; Пробел — включить сервис; e — изменить настройки;
a — применить; s — запустить/остановить; d — диагностика; q — выйти.
В редакторе Ctrl+S сохраняет изменения, Esc отменяет редактирование.
ID команд и ключи JSON остаются английскими для совместимости пресетов.

7. Только после проверки включите запуск вместе с системой

fdpi enable

Если появились проблемы с сетью:

fdpi stop

Сеть продолжит работать без обработки FDPI. Для отката настроек: fdpi rollback.
Журнал ошибок: fdpi logs. Полная диагностика: sudo /usr/bin/fdpi doctor.

Удаление: в каталоге проекта выполните sudo make uninstall.
Системные и пользовательские настройки сохранятся.

Важно: установка с root, автозапуск после перезагрузки и обход у вашего
провайдера требуют проверки на вашей системе. Реальный nfqws2, IPv4/IPv6,
HTTP/HTTPS и аварийная очистка проверены отдельно в изолированных namespace.
