# ╭─ Spotify Desktop ─╮

Профиль `spotify`, стратегия `spotify-desktop`.

```text
╭─ HTTPS ─────────────────────────────────────────────╮
│ API / авторизация / CDN → fake → split 1,midsld     │
│ Профиль выбран ≠ трек воспроизводится               │
╰────────────────────────────────────────────────────╯
```

Стратегия отправляет ложный пакет с изменённым TCP sequence, затем разделяет
HTTP/TLS-данные в позициях `1,midsld`. Для fake используются два повтора.
Это измеряемый кандидат, а не универсальное решение для каждой сети.

Покрытие: `spotify.com`, `scdn.co`, `spotifycdn.com`, `spotifycdn.net` и
четыре конкретных имени аудио-CDN Akamai. Вся общая зона `akamaized.net`
не включена: она обслуживает сторонние приложения.

```bash
fdpi config enable spotify on
fdpi apply
fdpi test apresolve.spotify.com
```

В TUI: **Сервисы → Spotify Desktop → Space → a**. Перед применением
проверьте выбранные остальные профили. `fdpi lab spotify` сравнивает
HTTPS-доступность; он не управляет аккаунтом и не воспроизводит музыку.

Нативный AP-протокол Spotify, в том числе на TCP 4070 и 443, не равен
HTTP/TLS и этим доменным профилем не обрабатывается. FDPI также не меняет
регион аккаунта, подписку, авторизацию и лицензионные ограничения.

Spotify рекомендует проверять исключения firewall при проблемах соединения:
[официальная справка](https://support.spotify.com/us/article/spotify-is-offline/).
Подтверждённого публичного исчерпывающего списка доменов Desktop здесь нет;
профиль опирается на фактические ответы resolver и имена наблюдаемых сервисов.

## Что проверено

На тестовой машине стратегия принята настоящим nfqws2. С привязкой к
физическому интерфейсу получены ответы resolver (HTTP 200), accounts (301),
open.spotify.com (302). Редирект — доказательство ответа сервера, а не входа
в аккаунт. Результаты CDN приведены в [evidence/spotify-direct-0.4.json](evidence/spotify-direct-0.4.json).

Spotify Desktop во время проверки был на паузе. Трек не запускался:
полное воспроизведение и нативный AP-трафик не подтверждены.
VPN оставлен включённым для связи с чатом; прямые пробы использовали только
временные точечные маршруты и исключения firewall, затем удалённые.
