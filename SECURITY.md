# Безопасность

Для непубличного сообщения используйте GitHub private vulnerability reporting,
если он включён в репозитории. Не прикладывайте действующие секреты.

FDPI запускает nfqws2 с правами администратора. Системный конфиг, бинарный файл
и Lua-зависимости должны принадлежать root и не быть доступны для общей записи.
TUI работает от обычного пользователя. Административные операции используют sudo.
FDPI меняет только собственную таблицу nftables; сторонний kill switch может
запрещать прямой доступ. Не исправляйте это глобальным flush firewall.
