# ╭─ История FDPI ─╮

## 0.4.1 · 2026-11-08

- Пункт «Удалить FDPI» в настройках с подтверждением и сохранением профилей.
- Команда uninstall --yes; проверка остановки и очистки перед удалением файлов.
- Упрощено публичное оформление; расширен справочник DPI.

## 0.4.0 · 2026-11-08

- Единый TUI: боковая навигация, карточки, рамки и палитра FDPI.
- Общая оболочка для разделов, форм, подтверждений и мастера установки.
- Адаптация к компактным терминалам и проверка границ всех экранов.
- Реальное состояние автозапуска из systemd; выбранные профили не названы PASS.
- Публичная документация, иллюстрация баннера, реальные PTY-снимки и GitHub CI.

## 0.3.0 · 2026-11-08

- Переход на внешний nfqws2 с собственным Go-компилятором профилей.
- Исправление выбора интерфейса rawsend для IPv4/IPv6 при VPN/PBR.
- Проверка страницы, JPEG и JSON API YouTube; интеграция с TUI и подбором.
- Прямые проверки YouTube, включая диапазон 1 МиБ AV1-видео.

## 0.2.0 · 2026-11-08

- Интерактивная установка, формы своих сервисов и русские сообщения.
- NFQUEUE 24000 и явное подтверждение замены zapret/zapret2.
- Исправление зависимостей zlib-ng-compat на CachyOS.
