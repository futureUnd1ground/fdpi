# FDPI для Windows

FDPI управляет доменными стратегиями обхода DPI: выбирает сервисы, подбирает
стратегии и следит за фоновой службой. На Windows вместо nfqueue/nftables
используется движок **winws2** (zapret2, WinDivert) — те же стратегии
(фрагментация, fake-пакеты, QUIC), тот же TUI.

## Быстрый старт

1. Скачайте `fdpi-windows-amd64.zip` из [релизов](../../releases) и распакуйте
   в отдельную папку, например `C:\FDPI`. Архив уже содержит всё необходимое:
   `fdpi.exe`, `winws2.exe`, подписанный драйвер `WinDivert64.sys`,
   `WinDivert.dll`, Lua-библиотеки стратегий и конфигурацию по умолчанию.
2. Запустите `fdpi.exe` (двойной клик в `cmd`/Windows Terminal — нужен
   терминал). Откроется мастер первого запуска:
   - проверка компонентов;
   - выбор сервисов (YouTube, Discord, Steam, Spotify) и стратегии;
   - установка службы Windows (одно согласие UAC) и её запуск;
   - тест доступности выбранных доменов.
3. Дальше — основной TUI: обзор, сервисы, стратегии, **подбор стратегии**,
   журнал, настройки. Клавиши: `j`/`k` или стрелки, `Enter`, `q` — выход.

Служба `fdpi` стартует автоматически при входе в систему. Обработка идёт
только для доменов включённых профилей и только первых пакетов соединений
на портах 80/443 — остальной трафик не затрагивается.

## Требования

- Windows 10/11 (x64). Драйвер WinDivert 2.2.2 подписан и ставится
  автоматически при первом запуске службы; отдельной установки не требуется.
- Права администратора — только для установки/управления службой (UAC);
  сам интерфейс работает без них.

## Управление из командной строки

```
fdpi                 интерфейс (TUI)
fdpi setup           мастер первого запуска заново
fdpi start|stop|restart   управление службой (с UAC)
fdpi status [--json]      состояние службы и движка
fdpi test ДОМЕН           DNS, TCP, TLS, HTTPS
fdpi lab СЕРВИС           подбор стратегии (перебор с проверкой домена)
fdpi logs [--follow]      журнал движка (engine.log)
fdpi doctor               диагностика
fdpi service-install      установить службу с автозапуском
fdpi service-remove       остановить и удалить службу
```

Настройки пользователя (черновик): `%APPDATA%\fdpi\config.json`.
Системные настройки службы: `%ProgramData%\FDPI\config.json`,
журнал: `%ProgramData%\FDPI\logs\engine.log`.

## Как это работает

1. Служба Windows запускает `fdpi daemon`, тот — `winws2.exe` с фильтром
   WinDivert на исходящий TCP/80,443 и UDP/443.
2. Для TLS ClientHello и HTTP-запросов к доменам из включённых профилей
   движок применяет выбранную стратегию: подменные пакеты (`fake` с
   искажённым sequence/TTL), фрагментация (`multisplit`), фрагментация с
   перестановкой (`multidisorder`), QUIC Initial fake (`quic`).
3. Домены второго уровня из hostlist покрывают поддомены автоматически.

Движок winws2 — это Windows-вариант nfq2 из [zapret2](https://github.com/bol-van/zapret2)
(подробности в `docs/ENGINE.md`), собранный кросс-компиляцией mingw-w64
скриптом `scripts/build-engine-windows.sh`. WinDivert — отдельный проект
basil00 (LGPL/GPL), бинарные файлы лежат в `third_party/windivert/`.

## Сборка из исходников (Linux)

```
make dist-windows     # build/windows + fdpi-windows-amd64.zip
```

Нужны: Go 1.24+, mingw-w64 (`x86_64-w64-mingw32-gcc`), curl, zip.
Скрипт сам скачает Lua 5.4 и zlib, применит патч к zapret2 на закреплённый
commit и соберёт `winws2.exe`.

## Удаление

```
fdpi service-remove
```
Удалите папку с программой. Пользовательские настройки в `%APPDATA%\fdpi`
и `%ProgramData%\FDPI` можно удалить вручную — они не влияют на систему.
